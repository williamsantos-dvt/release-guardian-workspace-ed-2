# Exemplo OpenSpec — Sistema de Empréstimos de Biblioteca

Exemplo completo e neutro (não relacionado com o Release Guardian) de uma
mudança OpenSpec bem formada. Usa-o como referência de forma e profundidade ao
escrever a tua própria mudança.

```text
openspec-example/
├── proposal.md
├── design.md
├── tasks.md
└── specs/
    └── loan-notifications/
        └── spec.md
```
